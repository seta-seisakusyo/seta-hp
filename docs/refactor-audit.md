# 管理画面の追加レビュー対応

## 修正

- 管理フォームと削除確認に共通の実行中ガードを追加。同一イベント内の連打、保存・削除中の閉じる操作と対象切替を抑止する。失敗時は入力を保持して再操作できる。
- 管理一覧の取得失敗を画面に表示し、再試行できるようにした。空一覧とエラーを区別し、書き込み成功後の再取得失敗は保存・削除が完了したことも示す。
- 商品・制作事例・お知らせの保存値への変換と検証をZodスキーマへ集約。HTML変換後のVARCHAR上限、タグの結合後の長さ、価格・JSON IDのDB整数上限、制作事例の画像URL長を検証する。各APIの重複変換と不要なサニタイズヘルパーを削除した。
- URLのID・JSONのID・価格・ページングでDB整数上限を共有。ページングは十進整数を読み取り、乗算後のオフセット超過も先頭ページへ戻す。未指定時の既存API契約は維持する。
