## 2. 命名にいたるまでの検討プロセス

### 検討した候補と却下理由

最初は「SETA Craft」(瀬田=苗字/地名 + Craft=ものづくり)で始めたが、複数の候補を検討する過程で先行ブランドとの衝突や読みづらさが見つかり、最終的に「飾Love」に到達した。

| 順番 | 候補名 | 却下理由 |
|---|---|---|
| 1 | **SETA Craft** | 「セトクラフト株式会社」(愛知県瀬戸市の雑貨企画会社)と読み・カタカナ表記が酷似。装飾系で業界も近く、混同リスクが高いため変更を判断 |
| 2 | **Kazaru Lab** | 「kazaru.art(アールビバン株式会社)」が大手アート販売サービスとして既存。同名・近接業界で衝突リスク。また自己紹介時に「カザル・ラボ」と発音しにくいという課題も |
| 3 | **Kazarabo / かざらぼ** | 衝突ゼロで4音という強さがあったが、「Lab」が「rabo」になることで意味が伝わりにくくなる(ローマ字直読みに見える)という違和感 |
| 4 | **Kazaken / 飾研** | 株式会社カザケン(岡山県の老舗ゼネコン)が `kazaken.co.jp` で活動中。業界は違うが検索で混同 |
| 5 | **飾り屋(かざりや)** | 飾りやドットコム、飾工房、かざりや 鐐、飾りや(沖津ななみ)など装飾・アクセサリー系で既に複数の同名事業者が存在 |
| 6 | **Kaza Love / kaza-love** | 海外アーティスト「Kaza Love」が音楽配信(Apple Music/Spotify等)で活動中。ただし業界が完全に違う(音楽 vs ディスプレイ)ため法的衝突リスクは低い |
| 7 | **飾Love(かざらぶ)** | **採用**。漢字英字ハイブリッド表記の「飾Love」自体は完全な独自表記で衝突なし。英字綴り `kaza-love` も他業界のみで実害なし |

### 採用した最大の理由

**「飾らない愛」という慣用句の対義語として「飾る愛」が成立する**ことに気づいたのが転換点。これは:

- コレクター心と完璧に一致する(好きだから飾りたい、大事だから見せたい)
- 商品の本質を一語で表現できている
- 「飾る愛」というキャッチコピーが**他社では生み出せない強さ**を持っている

そのうえで:

- **漢字「飾」+英字「Love」のハイブリッド表記**が現代的でロゴ映えする
- **「かざらぶ」**の4音は言いやすく、覚えやすい
- **完全な独自表記**で先行ブランドとの衝突がない

## 4. ブランドの世界観・トーン

### コンセプトの三本柱

1. **「飾る愛」というコピー**
   - 「飾らない愛」の対義語として生まれた新概念
   - コレクター心を一語で言語化したもの
   - ブランドの存在意義そのもの

2. **「研究の場」というニュアンス**
   - 「Love」は感情の表現だが、製作所としての**実直さ・職人感**は別の経路で伝える必要がある
   - 「**飾り方を研究する**」という探究心を、サイト・SNSで継続的に発信する
   - 例: 試作品の比較、素材検討、配置研究などを公開していく

3. **「高岡発」という土地のルーツ**
   - 富山県高岡市は400年の伝統工芸の歴史を持つものづくりの街(銅器・漆器で有名)
   - この土地で、トレカディスプレイという新しい工芸を生み出すというストーリー
   - 名刺や About ページで「**富山県高岡市から発送**」と明示する

### トーン&マナー

| 要素 | 方針 |
|---|---|
| **言葉づかい** | 丁寧だが堅すぎない。コレクター仲間としての距離感 |
| **写真の世界観** | 暗めの背景・暖色系のライティング・アートピース感。AWARD HISTORY 壁(大谷翔平 MVP/受賞歴 展示)を象徴ビジュアルとして使う |
| **一人称** | 「**私**」で統一(個人事業主の温度感、業者感を消す) |
| **色味(推奨)** | アクリルの透明感+ゴールド/ブロンズ(高級感)+黒(締まり) |
| **絵文字・記号** | 本文での絵文字・「♡」は使わない(推し活系の軽さを避ける)。ロゴマーク内のハート意匠は許容(タグライン「飾る愛」の字義表現) |

### 避けるべき表現

- ❌ 「**カザラブ**」とカタカナで書く → 海外アーティスト Kaza Love と混同
- ❌ 「**かざらぼ**」と書く → 「Lab(研究所)」を想起させ意味が変わる
- ❌ 「**SETA Craft**」を残す → 旧ブランドとの混乱を招く
- ❌ 推し活全般・恋愛系の連想を強める表現 → 野球コレクター(40〜50代男性層含む)に響かない
